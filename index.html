Перед началом

Компьютерное зрение (Computer Vision) — область ИИ, где компьютер учится понимать фото и видео: видеть объекты, распознавать лица и знаки, отслеживать движение и анализировать сцену. Так работают Face ID, беспилотные машины, камеры на дорогах и анализ снимков МРТ.

Четыре главные задачи

КлассификацияЧто на фото? Один ответ на всю картинку.
ДетекцияЧто и где? Рамки вокруг объектов.
СегментацияКакие пиксели принадлежат объекту?
Ключевые точкиУзлы лица, кисти, скелет человека.

Какой инструмент выбрать

ЗадачаИнструмент
Обрезать, повернуть, включить веб-камеруOpenCV — база для работы с кадром
Считать жесты, найти лицо и скелетMediaPipe — готовые модели от Google, быстро работают даже на телефоне
Найти и посчитать машины, людейYOLO — детекция в реальном времени «из коробки»
Создать и обучить свою нейросетьPyTorch или TensorFlow

Подготовка. Установите библиотеки одной командой (лучше в виртуальном окружении):

pip install opencv-python mediapipe==0.10.14 ultralytics torch torchvision tensorflow

Положите рядом со скриптами любую картинку photo.jpg (лучше с людьми или машинами) и убедитесь, что веб-камера работает.

Тяжёлые пакеты (torch, tensorflow) весят по несколько сотен мегабайт — ставьте заранее. Если Python 3.13 и выше, и установка падает с ошибкой, используйте Python 3.10–3.12.

Работа 1

OpenCV — глаза программы

Цель: научиться читать картинку, менять её и показывать видео с веб-камеры. Картинка для компьютера — таблица чисел (пикселей).

Основные команды

КомандаЧто делает
cv2.imread(path)читает картинку в массив (цвета в порядке BGR, не RGB!)
image.shapeвысота, ширина, число каналов
cv2.cvtColor(img, код)меняет цветовую модель (серый, HSV…)
cv2.resize(img, (w, h))меняет размер
cv2.GaussianBlur(img, (15,15), 0)размытие
cv2.Canny(img, 100, 200)поиск контуров
cv2.rectangle / putTextрисует рамку и подпись
cv2.imshow / imwriteпоказывает окно / сохраняет файл
cv2.VideoCapture(0)открывает веб-камеру

Код — cv_basic.py

import cv2

image = cv2.imread("photo.jpg")
print("Размер:", image.shape)        # (высота, ширина, 3)

gray = cv2.cvtColor(image, cv2.COLOR_BGR2GRAY)
edges = cv2.Canny(gray, 100, 200)    # контуры

cv2.imshow("Original", image)
cv2.imshow("Edges", edges)
cv2.waitKey(0)                       # ждём нажатия клавиши
cv2.destroyAllWindows()

Задание 1.2 (★): «детектор цвета» — найти красный предмет 
import cv2
import numpy as np

cap = cv2.VideoCapture(0)
while True:
    ok, frame = cap.read()
    if not ok:
        break
    hsv = cv2.cvtColor(frame, cv2.COLOR_BGR2HSV)
    mask = cv2.inRange(hsv, np.array([0, 120, 70]), np.array([10, 255, 255]))
    contours, _ = cv2.findContours(mask, cv2.RETR_EXTERNAL, cv2.CHAIN_APPROX_SIMPLE)
    for c in contours:
        if cv2.contourArea(c) > 1000:          # игнорируем мелкий шум
            x, y, w, h = cv2.boundingRect(c)
            cv2.rectangle(frame, (x, y), (x + w, y + h), (0, 255, 0), 2)
    cv2.imshow("Red finder", frame)
    if cv2.waitKey(1) == ord("q"):
        break
cap.release()
cv2.destroyAllWindows()

HSV удобнее RGB для поиска цвета: оттенок (H) отделён от яркости (V). Красный — около 0–10. Для синего попробуйте 100–130.

Работа 2

MediaPipe — руки, лицо и скелет

Цель: найти на видео кисть руки и 21 ключевую точку, а затем посчитать поднятые пальцы.

Мы используем классический интерфейс mp.solutions. Он работает в версии mediapipe==0.10.14 из команды установки выше.

Основные объекты

ОбъектЧто делает
mp.solutions.hands.Hands()модель поиска рук (точки 0–20)
mp.solutions.face_mesh468 точек лица
mp.solutions.poseскелет тела (33 точки)
hands.process(rgb_img)запускает модель; ждёт RGB
mp.solutions.drawing_utilsрисует точки и линии

Код — hands_demo.py

import cv2
import mediapipe as mp

mp_hands = mp.solutions.hands
draw = mp.solutions.drawing_utils
hands = mp_hands.Hands(max_num_hands=2, min_detection_confidence=0.6)

cap = cv2.VideoCapture(0)
while True:
    ok, frame = cap.read()
    if not ok:
        break
    frame = cv2.flip(frame, 1)                       # зеркало
    rgb = cv2.cvtColor(frame, cv2.COLOR_BGR2RGB)     # BGR -> RGB
    result = hands.process(rgb)
    if result.multi_hand_landmarks:
        for hand in result.multi_hand_landmarks:
            draw.draw_landmarks(frame, hand, mp_hands.HAND_CONNECTIONS)
    cv2.imshow("Hands", frame)
    if cv2.waitKey(1) == ord("q"):
        break
cap.release()
cv2.destroyAllWindows()

Работа 3

YOLO — найти всё и сразу

Цель: запустить готовую нейросеть, которая за один проход («You Only Look Once») находит на кадре объекты 80 классов: люди, кошки, машины, светофоры, рюкзаки и др.

Основные команды

КомандаЧто делает
YOLO("yolo11n.pt")загружает модель (n — nano, самая быстрая; s, m, l, x — точнее, но медленнее)
model(img)запускает детекцию на картинке, видео или кадре
results[0].plot()возвращает кадр с нарисованными рамками
results[0].boxesрамки: координаты xyxy, класс cls, уверенность conf
model.namesсловарь «номер класса → название»
model(img, conf=0.5)показывать только уверенные ответы

Код — yolo_demo.py

from ultralytics import YOLO
import cv2

model = YOLO("yolo11n.pt")          # скачается автоматически при первом запуске
results = model("street.jpg")       # положите рядом фото улицы

for box in results[0].boxes:
    name = model.names[int(box.cls)]
    print(name, round(float(box.conf), 2))

cv2.imshow("YOLO", results[0].plot())
cv2.waitKey(0)
cv2.destroyAllWindows()
Задание 3.1: YOLO с веб-камеры и счётчик людей 
from ultralytics import YOLO
import cv2

model = YOLO("yolo11n.pt")
cap = cv2.VideoCapture(0)
while True:
    ok, frame = cap.read()
    if not ok:
        break
    results = model(frame, conf=0.5, verbose=False)
    people = sum(1 for b in results[0].boxes if int(b.cls) == 0)   # класс 0 = person
    annotated = results[0].plot()
    cv2.putText(annotated, f"People: {people}", (20, 40),
                cv2.FONT_HERSHEY_SIMPLEX, 1, (0, 255, 255), 2)
    cv2.imshow("YOLO camera", annotated)
    if cv2.waitKey(1) == ord("q"):
        break
cap.release()
cv2.destroyAllWindows()

Работа 4

PyTorch — своя нейросеть

Цель: познакомиться с тензорами и обучить маленькую сеть распознавать рукописные цифры (набор MNIST: 60 000 картинок 28×28).

Основные понятия

КомандаЧто делает
torch.tensor([...])тензор — «многомерный массив» с поддержкой видеокарты
nn.Linear(in, out)слой сети
nn.ReLU()функция активации, добавляет нелинейность
nn.CrossEntropyLoss()функция потерь: насколько сеть ошибается
torch.optim.Adam(...)оптимизатор: подстраивает веса
loss.backward()считает, как менять веса (обратное распространение)
optimizer.step()делает шаг обучения

Код — torch_mnist.py

import torch
from torch import nn
from torchvision import datasets, transforms
from torch.utils.data import DataLoader

tf = transforms.ToTensor()
train = datasets.MNIST("data", train=True, download=True, transform=tf)
test = datasets.MNIST("data", train=False, download=True, transform=tf)
train_dl = DataLoader(train, batch_size=64, shuffle=True)
test_dl = DataLoader(test, batch_size=256)

model = nn.Sequential(
    nn.Flatten(),                 # 28x28 -> 784
    nn.Linear(784, 128), nn.ReLU(),
    nn.Linear(128, 10),           # 10 цифр
)
loss_fn = nn.CrossEntropyLoss()
opt = torch.optim.Adam(model.parameters(), lr=0.001)

for epoch in range(3):
    for x, y in train_dl:
        opt.zero_grad()
        loss = loss_fn(model(x), y)
        loss.backward()
        opt.step()
    correct = 0
    with torch.no_grad():
        for x, y in test_dl:
            correct += (model(x).argmax(1) == y).sum().item()
    print(f"Эпоха {epoch + 1}: точность {correct / len(test):.1%}")
Задание 4.1: меняем архитектуру

Измените число нейронов (128 → 32 и 512), добавьте ещё один слой, поменяйте lr и число эпох. Заполните таблицу: что изменили → какая точность → сколько секунд длилось обучение.

Задание 4.2 (★): сохранить и проверить модель 
torch.save(model.state_dict(), "mnist.pth")     # сохранить веса

Работа 5

TensorFlow и Keras — та же задача, другой стиль

Цель: решить ту же задачу с цифрами в Keras — высокоуровневом интерфейсе TensorFlow — и сравнить с PyTorch. Здесь обучение скрыто в одной команде fit.

Основные команды

КомандаЧто делает
keras.Sequential([...])собирает сеть из слоёв по порядку
layers.Dense(n)полносвязный слой
layers.Conv2D / MaxPooling2Dсвёрточные слои — «глаза» сети
model.compile(...)задаёт оптимизатор, потери и метрики
model.fit(x, y, epochs=n)обучение
model.evaluate / predictпроверка точности / предсказание

Код — keras_mnist.py

import tensorflow as tf
from tensorflow import keras
from tensorflow.keras import layers

(x_train, y_train), (x_test, y_test) = keras.datasets.mnist.load_data()
x_train = x_train[..., None] / 255.0       # добавляем канал, цвета 0..1
x_test = x_test[..., None] / 255.0

model = keras.Sequential([
    layers.Input(shape=(28, 28, 1)),
    layers.Conv2D(16, 3, activation="relu"),   # ищет простые узоры
    layers.MaxPooling2D(),                     # уменьшает картинку
    layers.Flatten(),
    layers.Dense(10, activation="softmax"),
])
model.compile(optimizer="adam",
              loss="sparse_categorical_crossentropy",
              metrics=["accuracy"])
model.fit(x_train, y_train, epochs=3, validation_split=0.1)
print(model.evaluate(x_test, y_test))
Задание 5.1: предсказать свою цифру

Нарисуйте цифру в Paint (белая на чёрном, 28×28), загрузите через cv2.imread(..., 0), поделите на 255 и вызовите model.predict(img.reshape(1, 28, 28, 1)). Угадала ли сеть?

PyTorch или TensorFlow? Оба обучают нейросети. PyTorch любят исследователи за гибкость и прозрачный цикл обучения. Keras проще для старта и удобен для мобильных и веб-приложений. Для классического машинного зрения «из коробки» выбирайте YOLO, а свою сеть обучайте, когда нужной модели нет.
